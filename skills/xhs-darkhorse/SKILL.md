# 小红书黑马爆文榜

> 发现小红书上正在悄悄起量的黑马爆文，看清哪些账号和内容最近突然跑出来了。

## 触发场景

- "查一下小红书黑马爆文榜"
- "XX 分类的黑马笔记"（如「居家装修黑马爆文榜」）
- "看看小红书最近有哪些黑马内容"
- "查某天的黑马爆文榜"

如果用户输入的分类无法匹配到标准分类，按「综合全部」查询；查询无结果时如实说明，不自动改查其他分类。

## 数据口径

- **榜单定位**：黑马爆文榜，近期互动表现突出的黑马笔记，**不限粉丝量级**；按单日出榜（返回笔记发布日期集中在统计窗口当天或前一天），**不是**七日爆款笔记周榜。
- **分类筛选**：25 个内容分类，不指定时默认「综合全部」。分类清单：综合全部、出行代步、医疗保健、休闲爱好、综合杂项、婚庆婚礼、居家装修、影视娱乐、星座情感、拍摄记录、学习教育、旅行度假、亲子育儿、日常生活、科学探索、数码科技、时尚穿搭、化妆美容、个人护理、美味佳肴、职业发展、宠物天地、新闻资讯、体育锻炼、潮流鞋包。
- **日期口径**：`rankDate` 为统计窗口**开始日期**，可查近 30 天内任意一天；数据每天 **17:30** 开始更新昨日数据（17:30 前查询昨日数据尚未生成）。工具内置默认日与断档自动回退（7 天前窗口）。
- **排序**：按互动总量从高到低，展示 TOP50（首次输出 TOP20，用户要看完整榜用 action="list" 补读）。
- **每条笔记**：标题、作者、粉丝数、发布时间、点赞数、评论数、收藏数、分享数、互动总数。

## 使用边界（积分保护）

- 每次调用数据服务都可能消耗积分（含空结果）；只执行用户明确要求的分类与统计窗口，不主动批量查询多个分类。
- 查询无结果时如实说明并给出可调整方向（换分类 / 更近的窗口），不自动改查其他分类。
- 工具在数据断档时会自动回退 7 天前窗口（最多 2 次 API 请求）并在回执注明——如实转述，不隐瞒回退事实。

## 输出规则

fetch 成功后按顺序完整输出（工具返回的 data 字段已含全部素材，原样呈现）：

1. **榜单表格**：序号、笔记信息（标题与作者主页均可点击）、互动总数、点赞数、评论数、收藏数、分享数、发布时间。首次输出 TOP20；总数超过 20 条时提示可以查看更多。数据断档自动回退时，在最前面注明回退事实。
2. **爆款规律分析**：标题特征表、内容主题表与可参考亮点（参考笔记带跳转链接）。
3. **分类查询提示**：列出 25 个可选分类，引导按分类继续查询。
4. **页脚**：逐字附带工具返回的 footer（数据源、分类、统计窗口、记录 id）。

### 呈现纪律

- 榜单表格不改成列表、不省略任何列；参考笔记链接保持完整可点击，不用被截断的 URL。
- 所有数值来自数据服务返回，如实展示，严禁估算或编造。
- 用户问"为什么"时，基于规律分析给出解读（标题句式、内容主题、收藏/分享比、黑马集中度），不脱离数据发挥。

## 面板与导出

- 侧栏「小红书黑马爆文榜」面板可直查榜单、看历史记录、导出小红书风格 HTML（可再导 PDF）。
- 用户要 HTML 导出时，引导到面板对应榜单详情页点「导出 HTML」——从本地已入库数据渲染，0 次数据请求，不重复扣积分。
